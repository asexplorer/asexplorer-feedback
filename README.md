# asExplorer feedback

This is where you report problems with [asExplorer](https://asexplorer.com) and suggest ideas for it.
asExplorer is a free file explorer for macOS, Windows and Linux: the layout of Windows Explorer with the
conventions of each platform. Its code is not here; this repository only collects feedback.

## Send feedback

- **[Report a problem](https://github.com/asexplorer/asexplorer-feedback/issues/new?template=1-problem.yml)**: something
  doesn't work, looks wrong or crashed.
- **[Suggest an idea](https://github.com/asexplorer/asexplorer-feedback/issues/new?template=2-idea.yml)**: something you
  miss, or something Finder or Explorer does better.

In the app: **Help › Send Feedback…** on macOS, or the command bar's **…** menu › **Send feedback…** on Windows and
Linux. Both open this repository's forms.

Before you write, please look through the [open issues](https://github.com/asexplorer/asexplorer-feedback/issues): if
yours is already there, give it a 👍. We sort ideas by votes.

## No GitHub account?

Write to **feedback@asexplorer.com**. In the app, **No GitHub Account? Email Us…** (macOS) or **No GitHub account?
Email us…** (Windows, Linux) starts the e-mail with your asExplorer version and system already filled in. E-mail
stays private; we may add what you report here without your name.

## Everything here is public

Issues, comments and your GitHub name can be seen by anyone. Please don't paste private file names, folder paths,
documents or screenshots that show something you'd rather keep to yourself. If you need to send something
private, use the e-mail address above.

## What happens next

We read every issue. You will see labels as it moves along (for example *bug*, *enhancement*, *question*), and
when a fix or an idea ships, the issue is closed with the version it is in, so GitHub tells you. Downloads and
release notes are on [asexplorer.com](https://asexplorer.com).

Please be kind: issues that are abusive or off topic are hidden or locked.
